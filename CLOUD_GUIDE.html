클라우드 배포 가이드

박물관 외부에서도 접근 가능하게 — 30분 완성
1

Supabase 가입 + 프로젝트 생성

5분

데이터베이스 + 사용자 인증을 무료로 제공하는 서비스입니다.

① 가입 페이지로 이동
→ GitHub 또는 이메일로 가입
② 새 프로젝트 만들기
  • Name: jamsa-museum
  • Database Password: 강한 비밀번호 (메모장에 따로 저장!)
  • Region: Northeast Asia (Seoul) ⭐
  • Plan: Free
2

SQL 스키마 한 번 실행

2분

데이터 테이블/검색함수/보안 정책을 한 번에 설치합니다.

① Supabase 대시보드에서 좌측 SQL Editor 클릭
② 같은 폴더의 schema.sql 파일 열기
→ 메모장에서 Ctrl+A → Ctrl+C (전체 복사)
③ SQL Editor에 붙여넣고 Run
Ctrl+V → 우하단 Run ▶ 클릭
✅ "Success" 메시지 확인
④ Authentication → Providers → Email 활성화
"Confirm email" 끄기 (즉시 가입 가능)
Save 클릭
3

환경변수 3개 복사

2분

Vercel 배포 시 필요합니다. 메모장에 따로 모아두세요.

Supabase 대시보드 → Project Settings (⚙) → API
변수명위치
SUPABASE_URL Project URL (https://xxxxx.supabase.co)
SUPABASE_ANON_KEY Project API keys → anon public
SUPABASE_SERVICE_ROLE_KEY Project API keys → service_role (Reveal 클릭)
🔒 service_role key는 절대 GitHub/공개 위치에 올리지 마세요. 누출 시 모든 데이터 노출됩니다.
4

GitHub + Vercel 배포

10분

GitHub Desktop 사용이 가장 쉬움 (명령어 없이 클릭만):

① GitHub Desktop 설치
→ 설치 → GitHub 가입/로그인
② 이 폴더를 GitHub에 올리기
  • GitHub Desktop 실행
  • File → Add local repository
  • 이 cloud-setup/ 폴더 선택
  • Publish repository 클릭
  • Private 체크 ⭐ → Publish
③ Vercel 가입 + 배포
"Continue with GitHub" 선택

가입 후:
  • Add New → Project
  • 방금 만든 GitHub 저장소 선택 → Import
  • Environment Variables 펼치기 → 4개 추가:
    SUPABASE_URL3단계 1번 값
    SUPABASE_ANON_KEY3단계 2번 값
    SUPABASE_SERVICE_ROLE_KEY3단계 3번 값
    ORG_IDjamsa
  • 하단 Deploy ▶ → 1-2분 대기
🎉 배포 완료 시 https://your-project.vercel.app 같은 URL이 발급됩니다.
5

첫 가입 = 자동 admin

3분

발급받은 URL 접속 → 로그인 화면 → 계정 만들기

이메일 + 비밀번호 (8자 이상) 입력 → 계정 만들기 클릭
✅ 첫 가입자는 자동으로 admin 권한 부여됨 (DB 트리거 작동)
💡 추가 직원 가입 시 자동으로 viewer 권한.
권한 변경은 Supabase SQL Editor에서:
update memberships set role = 'manager' where user_id = (select id from auth.users where email = 'user@example.com');
역할: admin > manager > inspector > viewer

🎉 클라우드 배포 완료!
