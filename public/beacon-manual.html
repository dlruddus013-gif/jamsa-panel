4사용 매뉴얼 — 단계별 가이드

현장에서 게이트웨이 도착 → 비콘 배부 → 모니터링까지
1

📡 게이트웨이 시리얼 등록

실제 장비가 박물관에 도착하면, 통합지도 메인 화면 상단의 비콘 인프라 패널에서 해당 카드의 "(시리얼 미등록 — 클릭해 입력)" 텍스트를 클릭하세요.

💡 시리얼은 게이트웨이 본체 뒷면 라벨에 있는 MAC 주소 또는 시리얼 번호입니다 (예: GW-MK110-A1B2C3). 입력 후 Enter 또는 입력칸 밖을 클릭하면 자동 저장됩니다.
2

🔧 야외 5곳 설치 후 상태 변경

단체식당·외부매표소·냉동창고·온실의 창고·수영장 5곳은 야외라 무선AP와 함께 신규 설치가 필요합니다. 설치가 완료되면 해당 카드의 → 가동 버튼을 누르세요.

💡 상태가 planned → active 로 바뀌며, installed_at 컬럼에 현재 시각이 자동 저장됩니다.
3

👥 직원에게 비콘 배부 + 시스템 등록

매일 출근 시 직원에게 BLE 비콘을 배부하고, 패널 헤더의 👥 직원-비콘 매핑 버튼을 누르세요. 직원 드롭다운에서 이름을 선택하고 비콘의 MAC 주소를 입력하면 끝.

💡 비콘 MAC은 비콘 본체 또는 포장 라벨에 표기되어 있습니다. 형식: AC:23:3F:11:22:33 (콜론 포함)
⚠️ 같은 비콘 UUID 는 1명의 직원에게만 활성화될 수 있습니다 (DB 유니크 제약). 이전 사용자에게서 회수했다면 그 사용자의 매핑을 먼저 "반납" 처리하세요.
4

📊 실시간 모니터링

패널은 30초마다 자동 새로고침되며, Supabase Realtime 구독으로 새 게이트웨이 추가/상태 변경 시 즉시 화면이 갱신됩니다.

각 카드의 점등 색상:

색상상태의미
🟢 초록온라인최근 5분 내 신호 수신
🟡 노랑유휴5분 ~ 1시간 신호 없음
🔴 빨강오프라인1시간 이상 신호 없음 → 점검 필요
⚪ 회색신호 없음등록은 됐지만 한 번도 수신 안됨
5

🔄 일과 종료 — 비콘 회수

직원 퇴근 시 비콘을 회수하면 매핑 모달에서 해당 항목의 "반납" 버튼을 누르세요.

💡 반납 처리하면 returned_at 에 시각이 기록되며, 같은 비콘을 다음날 다른 직원에게 새로 매핑할 수 있습니다.

5install_status 상태값 레퍼런스

게이트웨이 카드의 액션 버튼으로 변경 가능한 4가지 상태
상태의미사용 시점
active가동 중장비 설치 완료 + 시리얼 등록 완료
planned설치 예정위치는 정해졌지만 장비 미도착
offline오프라인설치는 됐지만 신호 두절 (긴급 점검)
maintenance점검 중일시적 유지보수 (오프라인 알람 끄기)

7자주 묻는 질문 (FAQ)

현장에서 자주 발생하는 문제와 해결법
Q. 게이트웨이를 설치했는데 카드가 계속 "신호 없음" (회색) 입니다
① 패널에서 해당 카드의 시리얼이 올바르게 입력됐는지 확인하세요. 장비 라벨의 시리얼과 100% 일치해야 매칭됩니다.
② 게이트웨이의 WiFi 연결 상태를 점검하세요. AP 와 함께 설치되어야 인터넷에 닿습니다.
③ 게이트웨이 펌웨어 설정에서 webhook URL 이 https://jamsa-panel.vercel.app/api/beacon-webhook 으로 되어 있는지 확인.
Q. 직원이 비콘을 분실/파손했을 때
매핑 모달에서 해당 항목의 "반납" 버튼을 눌러 비활성화하세요. 그러면 returned_at 이 기록되어 분실/파손 시점이 감사 로그에 남습니다. 새 비콘 도착 시 직원에게 다시 매핑하면 됩니다.
Q. 5곳 야외 설치 위치를 변경하고 싶어요
현재 5곳(단체식당·외부매표소·냉동창고·온실의 창고·수영장)은 정찬주 전무님 통보 기준으로 시드되어 있습니다. 위치를 변경하려면:
① Supabase Studio → Table editor → beacon_gateways 테이블에서 직접 수정
② 또는 추가 위치는 INSERT 로 새 행 추가 (spot_id 는 통합지도의 BASE_ZONES id 중 하나)
Q. 비콘이 여러 게이트웨이에 동시에 잡힐 때는?
RSSI(신호 강도)가 가장 강한 게이트웨이를 기준으로 그 직원의 위치를 판정합니다. process_beacon_detection 트리거가 자동으로 처리하며, presence_events 테이블에 입장/퇴장 이벤트로 누적됩니다.
Q. 패널이 통합지도에서 안 보여요
① 화면 좌하단 ▾ 패널 보기 버튼이 보이면 누르세요 (지도 풀스크린 모드일 수 있음)
② 패널 헤더의 ▴ 접기 토글로 접혀 있을 수 있습니다. localStorage 의 jp_beacon_infra_collapsed 값을 확인하거나 헤더를 클릭해 펼치세요.
③ Supabase 로그인이 안 되어 있으면 window.__supabase 가 없어서 데이터가 안 떠요 → 다시 로그인.
