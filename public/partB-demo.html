6🗄️ Supabase 신규 테이블 (2개)

📁 supabase/partB_alerts.sql 파일을 Supabase SQL Editor에 복붙 후 Run ▶️ 
CREATE TABLE auto_alerts (
  id            BIGSERIAL PRIMARY KEY,
  alert_type    TEXT NOT NULL,
  zone_id       TEXT,
  zone_name     TEXT,
  severity      TEXT,
  message       TEXT,
  channel_ch    INTEGER,
  people_count  INTEGER,
  auto_called   BOOLEAN,
  recipients    JSONB,
  created_at    TIMESTAMPTZ
);
-- 인덱스 3개 (created/zone/type)
CREATE TABLE staff_calls (
  id                BIGSERIAL PRIMARY KEY,
  staff_id          TEXT,
  staff_name        TEXT,
  zone_id           TEXT,
  zone_name         TEXT,
  message           TEXT,
  urgency           TEXT,
  distance_meters   INTEGER,
  sms_sent          BOOLEAN,
  responded_at      TIMESTAMPTZ,
  called_at         TIMESTAMPTZ
);
-- 인덱스 3개 (staff/zone/urgency)

7🌐 신규 API 엔드포인트 (3개) + 환경변수

엔드포인트메서드용도
/api/auto-alertsPOST알림 생성 → DB 저장 → (조건부) 자동 호출
/api/auto-alerts?range=todayGET오늘/주간 알림 이력 + 통계
/api/staff-dispatchPOST거리 기반 직원 선택 + Ppurio SMS 동시 발송
/api/forecast-kpi?type=forecastGET다음 7일 매출 예측 (선형 + 주말 1.4×)
/api/forecast-kpi?type=kpiGET직원별 + 종합 KPI 집계
🔑 Vercel 환경변수 (선택): PPURIO_USERNAME · PPURIO_API_KEY · PPURIO_SENDER
미설정 시에도 모든 기능 작동 — SMS만 발송되지 않고 staff_calls.sms_sent=false로 기록
