5실제 사용 시나리오

📝 시나리오 A — 부족 재고 자동 보충
1
시설맵 → 구역 → 재고 0 제품 행 클릭
2
펼침 패널 → 📝 품의 작성 → 부족 수량·AI 시세 단가 자동 채움
3
"📤 제출" → 헤더 📋 품의/결제 [3] 빨간 배지 +1
4
관리자: 승인 → 발주 → "💳 결제 등록" 단축 버튼 클릭
5
결제 폼 자동 채움 (금액·거래처·품의ID) → 등록 → 품의 자동 paid
6
"→ 입고완료" → 재고 +10 자동 증가 + 활동로그 자동 기록
💳 시나리오 B — 카드 영수증만 등록
1
📋 품의/결제 → 결제 내역 탭
2
"+ 결제 등록" → 카드/금액/거래처 입력
3
품의 연결 안 함 → 독립 결제로 저장
4
상단 KPI 💳 카드 누적에 자동 합산
🔁 자동 동기화 매트릭스
트리거자동 결과
결제 등록 (품의 연결)→ 품의 paid 처리, paymentId 연결
품의 → received→ prods 수량 +N, hist '입고' 생성
품의 생성/상태변경→ 재고 활동로그에 동시 기록
결제 삭제→ 연결 품의 paymentId 해제
