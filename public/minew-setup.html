1Python 설치 (Windows)

박물관 PC 에 Python 환경 구축 (Microsoft Store 권장)
A

Microsoft Store 에서 설치

시작 메뉴 → Microsoft Store 실행 → 검색창에 Python Install Manager 입력 → 설치.

💡 권장 버전: Python 3.11 또는 3.12 (3.14 은 일부 패키지 호환성 문제 가능)
B

설치 확인

명령 프롬프트 (cmd) 또는 PowerShell 열고:

python --version
pip --version

둘 다 버전이 찍히면 OK. pip --version 이 실패하면 다음 단계로.

2FastAPI + Uvicorn 설치

Minew 게이트웨이가 POST 할 수신 서버 프레임워크
pip install fastapi uvicorn requests
⚠️ pip 가 안 잡히면: python -m pip install fastapi uvicorn requests

참고: requests 는 우리가 뒤에서 만들 bridge.py 가 사용합니다.

3minew_server.py 실행

BLE 게이트웨이 수신 + 로컬 SQLite 저장
A

설치 디렉토리

첨부받은 minew_server.py 파일을 다음 경로에 복사:

C:\minew_server\minew_server.py
B

실행

cd C:\minew_server
python minew_server.py

창이 떠 있는 동안 BLE 데이터 수집됩니다. 창을 닫지 마세요. (자동 시작 방법은 6단계)

C

생성되는 파일

minew_ble_data.db
SQLite DB — 게이트웨이 + 비콘 raw 데이터
minew_received.jsonl
수신 전체 로그 (1줄 = 1 JSON)
raw_payloads/
바이너리 원본 페이로드 폴더

4Windows 방화벽 열기

박물관 LAN 의 다른 PC + Minew 게이트웨이가 8080 포트에 접속 가능하도록

PowerShell 또는 cmd 를 관리자 권한으로 실행 후:

netsh advfirewall firewall add rule name="BLE HTTP Server 8080" dir=in action=allow protocol=TCP localport=8080
💡 한 번만 실행하면 됩니다. 삭제하려면 name="BLE HTTP Server 8080" 동일 이름으로 delete rule.

5minew_server.py 엔드포인트

설치 후 다음 URL 들로 접속 (서버IP = 박물관 PC LAN IP, 같은 PC면 localhost)
POST/minew
Minew 게이트웨이 webhook 수신 URL
게이트웨이 설정에 이 주소를 등록 (JSON + Binary 자동 분기)
GET/health
{ status: "running", receive_url: "/minew" }
GET/logs?limit=30
최근 N건 (DESC by id) — 평면 컬럼 (gateway_mac, beacon_mac, rssi, uuid, major, minor, raw_file)
GET/raw/{log_id}
특정 id 의 행 전체 + raw_json 파싱된 객체
💡 저장: minew_ble_data.db (SQLite) + minew_received.jsonl + raw_payloads/ 폴더
JSON 페이로드의 다양한 키명을 자동 인식 (gateway_mac / gatewayMac / gw_mac / device_mac / mac 등 → find_value 재귀 탐색)
💡 Minew 게이트웨이 관리 페이지 (보통 192.168.1.xxx) 에 접속 → "데이터 전송"/"Webhook" 메뉴에서
http://서버IP:8080/minew 등록 → 전송 주기 1초~3초 권장

🌉클라우드 forward 브리지 설치

Minew 가 박물관 PC 의 minew_server.py 로 보낸 데이터를 → 우리 Vercel /api/beacon-webhook 으로 자동 forward
A

브리지 스크립트 다운로드 (v2 · 2026-05-25)

실제 minew_server.py 엔드포인트 사양(`/logs?limit=N` DESC + `/raw/{id}`) 에 맞춰 보정된 버전. 박물관 PC 의 minew_server.py 옆에 복사:

C:\minew_server\jamsa-minew-bridge.py

PowerShell 로 직접 다운로드:

curl -o C:\minew_server\jamsa-minew-bridge.py https://raw.githubusercontent.com/dlruddus013-gif/jamsa-panel/main/scripts/jamsa-minew-bridge.py
💡 브리지는 minew_server.py 와 별도 콘솔 창에서 동시에 실행됩니다. minew_server 가 SQLite 에 적재하면 → 브리지가 3초마다 새 행만 골라서 → Vercel 로 forward.
B

브리지 실행

새 명령 프롬프트 창에서 (minew_server.py 와 별도로):

cd C:\minew_server
python jamsa-minew-bridge.py --verbose

화면에 ✓ #ID gw=... beacons=N 가 찍히면 정상 forward 중입니다.

C

옵션 사용자화

python jamsa-minew-bridge.py \
    --minew    http://localhost:8080 \
    --webhook  https://jamsa-panel.vercel.app/api/beacon-webhook \
    --interval 3 \
    --state-file C:\minew_server\bridge-state.json \
    --verbose
--minew
minew_server.py 의 base URL
--webhook
forward 대상 (Vercel)
--interval
폴링 주기 (초, 기본 3)
--state-file
마지막 처리 ID 저장
D

확인 (Vercel)

브라우저로 https://jamsa-panel.vercel.app/api/beacon-webhook?recent=1 열어 마지막 수신 데이터 확인.

또는 통합관리 시스템 → 통합지도 → 비콘 게이트웨이 카드의 점등이 🟢 온라인 으로 바뀌는지 확인.

7PC 켜질 때 자동 시작 (작업 스케줄러)

박물관 PC 재부팅 시 minew_server.py + bridge 자동 기동
1

시작 → 작업 스케줄러 검색 → 실행

2

오른쪽 패널 → 작업 만들기 클릭 (단순 작업 X, 일반 작업)

3

일반 탭: 이름 JamsaMinewServer · "사용자 로그온 여부에 상관없이 실행" 체크

4

트리거 탭: 새로 만들기 → "시스템 시작 시"

5

동작 탭: 새로 만들기 → 프로그램 시작

프로그램/스크립트: python.exe

인수: C:\minew_server\minew_server.py

시작 위치: C:\minew_server

6

같은 방식으로 JamsaMinewBridge 작업도 추가:

인수: C:\minew_server\jamsa-minew-bridge.py

시작 위치: C:\minew_server

⚠️ 작업 스케줄러로 실행할 때는 콘솔창이 보이지 않습니다. 로그를 보려면 stdout 을 파일로 redirect 하거나, 처음에는 cmd 창에서 직접 실행해 동작 확인 후 스케줄러 등록을 권장합니다.

8모니터링 + 트러블슈팅

정상 동작 확인 + 문제 해결
GEThttp://서버IP:8080/health
200 OK 면 minew_server.py 정상
GEThttp://서버IP:8080/logs
최신 수신 로그 (브라우저에서 바로 확인)
GETjamsa-panel.vercel.app/api/beacon-webhook?ping=1
Vercel 측 수신 endpoint 헬스 체크
💡 점등이 안 바뀌는데?
① minew_server.py 콘솔에 데이터 들어오는지 확인
② bridge.py 콘솔에 ✓ 가 찍히는지 확인
③ Vercel ?recent=1 으로 최근 수신 페이로드 확인
④ 통합관리 시스템 → 게이트웨이 카드에 시리얼이 입력돼 있는지 확인
⑤ 시리얼이 게이트웨이가 보내는 gatewaySerial 필드와 정확히 일치해야 last_seen_at 자동 갱신

9(선택) WSL 사용

Windows + Linux 하이브리드로 운영하고 싶을 때

PowerShell 관리자 권한:

wsl --install
wsl --install -d Ubuntu-22.04

WSL 환경에 Python + minew_server.py 를 설치하고, Windows 호스트에서 http://localhost:8080 으로 접근 가능. 네이티브 Windows 보다 systemd 친화적이지만, 일반적으로는 1~8 단계로 충분합니다.
