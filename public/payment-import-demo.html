3🔍 4가지 형식 자동 감지 (헤더 매칭)

형식판별 헤더매핑된 필드결제 방식
🧾 홈택스 매입세금계산서 공급자 + 공급가액 또는 합계금액 작성일자 → date · 공급자 → vendor · 합계금액 → amount · 승인번호 → ref 이체
💳 홈택스 카드매입 이용가맹점 + 이용금액 이용일자 → date · 이용가맹점 → vendor · 이용금액 → amount 카드
🏦 은행 거래내역 출금액 / 입금액 또는 적요 + 잔액 거래일시 → date · 적요 → vendor · 출금/입금 → amount · 거래번호 → ref 출금→이체 / 입금→수익
💳 카드 이용내역 이용일 + 가맹점 이용일자 → date · 이용가맹점 → vendor · 이용금액 → amount 카드
💡 자동 헤더 행 탐색: 홈택스처럼 1~5행에 메타데이터(파일제목/조회기간 등)가 있어도 헤더 행을 자동 감지해서 처리합니다.

4📱 은행 알림 SMS → Webhook 자동 등록 (선택)

설정 방법 (Tasker / Macrodroid)
  1. 안드로이드폰에 Tasker 또는 Macrodroid 설치
  2. 프로파일: SMS 수신 → 발신자 15881111 (KB), 15885555 (신한) 등
  3. 액션: HTTP POST → https://jamsa-panel.vercel.app/api/bank-webhook
  4. Body: {"text": "%SMSRB"}
  5. Header: Authorization: Bearer YOUR_TOKEN
  6. Vercel 환경변수: BANK_WEBHOOK_TOKEN 동일 값 등록

5🔄 오픈뱅킹 자동 동기화 (5분 주기)

설정 절차
  1. openbanking.or.kr → 이용기관 등록
  2. 앱 생성 → client_id, client_secret 발급
  3. 사용자 인증 → access_token 발급
  4. 계좌 등록 → 핀테크이용번호(fintech_use_num) 획득
  5. Vercel 환경변수 4개 등록:
    • OPENBANKING_CLIENT_ID
    • OPENBANKING_CLIENT_SECRET
    • OPENBANKING_ACCESS_TOKEN
    • OPENBANKING_FINTECH_USE_NUM
  6. 모달 우상단 "🟢 실시간 ON" 토글 → 5분 주기 자동 폴링 시작
✅ 환경변수 미설정 상태에서도 시스템은 정상 작동 (수동 업로드만 사용)
동기화 흐름
// 5분마다 자동 호출 GET /api/openbanking-sync?since=2026-05-09 // 응답 (성공) { "ok": true, "count": 3, "rows": [ { "date": "2026-05-10", "vendor": "한국전력공사", "amount": 142000, "type": "transfer", "source": "오픈뱅킹" }, ... ] } // 환경변수 미설정 시 { "ok": false, "reason": "오픈뱅킹 환경변수 미설정", "configured": { ... } }

7🗄️ Supabase 스키마 (선택)

📁 supabase/payments_import.sql 파일을 SQL Editor에 붙여넣고 Run ▶️
CREATE TABLE payments_imported ( id BIGSERIAL PRIMARY KEY, date DATE NOT NULL, vendor TEXT NOT NULL, amount BIGINT NOT NULL, type TEXT, -- card | transfer | income ref TEXT, memo TEXT, source TEXT, -- 홈택스/은행/카드사/openbanking/bank_webhook format TEXT, -- 자동 감지된 형식 키 raw_data JSONB, -- 원본 보존 imported_at TIMESTAMPTZ DEFAULT NOW(), UNIQUE (date, amount, vendor) -- 중복 자동 방지 ); CREATE INDEX ON payments_imported(date DESC); CREATE INDEX ON payments_imported(vendor); CREATE INDEX ON payments_imported(source, imported_at); -- 월별 집계 뷰 CREATE VIEW v_payments_monthly AS SELECT DATE_TRUNC('month', date), type, source, COUNT(*), SUM(amount) FROM payments_imported GROUP BY 1, 2, 3;
