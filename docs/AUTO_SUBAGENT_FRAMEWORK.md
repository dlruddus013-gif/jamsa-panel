# 자동 서브에이전트 운영 프레임워크

최종 정리: 2026-05-10

## 1. 핵심 개념

자동 서브에이전트는 시설, 재고, 안전, 업무일지 데이터를 한 화면에서 점검하고 필요한 조치를 바로 실행하도록 돕는 운영 관제 기능입니다.

## 2. 4단계 운영 흐름

### 1단계: 자동 수집

- 시설 보완과제
- 재고 수량 및 요청서
- 안전 사고 및 일일 점검
- 업무일지 작성 여부
- 활동 기록

### 2단계: 서브에이전트 분석

- 시설 에이전트: 미완료, 긴급, 기한초과 과제 확인
- 재고 에이전트: 최소수량 이하 품목과 요청서 확인
- 안전 에이전트: 사고, 점검 누락, AI 분석 이력 확인
- 업무일지 에이전트: 당일 업무일지 작성 여부 확인

### 3단계: 위험도 분류

- 정상: 별도 조치 없음
- 관찰: 확인 또는 기록 보완 필요
- 긴급: 즉시 담당자 확인 및 보완과제 등록 필요

### 4단계: 실행 연결

- `이동`: 관련 모듈 화면으로 이동
- `과제 등록`: 시설 보완과제 자동 생성
- `자동 감시`: 추천 조치 수를 상단 배지로 표시
- `활동 기록`: 주요 조치 이력 저장

## 3. 역할별 사용법

### 관리자

1. 상단 `서브에이전트` 버튼을 눌러 전체 위험 상태를 확인합니다.
2. 긴급 또는 관찰 항목을 먼저 확인합니다.
3. 필요한 추천 조치를 보완과제로 등록합니다.
4. 활동 기록에서 조치 이력을 확인합니다.

### 담당자

1. 본인 업무와 관련된 추천 항목을 확인합니다.
2. `이동` 버튼으로 해당 모듈에 들어갑니다.
3. 실제 조치 후 업무일지 또는 보완과제를 갱신합니다.

### 조회자

1. 현재 상태와 추천 조치 수를 확인합니다.
2. 위험 항목을 관리자에게 공유합니다.

## 4. 판단 기준

| 에이전트 | 확인 데이터 | 위험 신호 | 실행 |
|---|---|---|---|
| 시설 | 보완과제 | 미완료, 긴급, 기한초과 | 시설점검 이동, 과제 등록 |
| 재고 | 제품 수량, 요청서 | 최소수량 이하, 미처리 요청 | 재고관리 이동, 발주 확인 |
| 안전 | 사고, 점검, AI 이력 | 사고 발생, 점검 누락 | 안전관리 이동, 후속 점검 |
| 업무일지 | 당일 기록 | 오늘 기록 없음 | 업무일지 작성 |
