## 주요 기능별 점검

### 1. 로그인/권한

상태: 정상

확인 내용:

- 통합 로그인은 아이디 또는 이메일을 받습니다.
- 기본 계정은 다음과 같습니다.
  - `admin / admin1234`: 전체 관리자
  - `mgr / mgr1234`: 관리자급
  - `ins1 / ins1234`, `ins2 / ins1234`: 점검자
  - `viewer / viewer1234`: 조회자
- 로그인 사용자는 `jamsa_current_user`에 저장되어 새로고침 후 복원됩니다.
- 재고 모듈은 별도 역할(`master`, `staff`, `viewer`)로 변환되어 권한을 적용합니다.

주의:

- 소스에 기본 비밀번호가 포함되어 있으므로 실제 운영에서는 Supabase Auth 계정/권한만 사용하도록 정리하는 것이 좋습니다.

### 2. 홈 대시보드

상태: 조건부 정상

확인 내용:

- 상단 모듈 전환: 홈, 시설점검, 재고관리, 안전관리, CCTV 관제
- 업무일지, 활동 기록, 백업/복원 모달 진입 가능
- 지도 모드는 네이버 Client ID가 있으면 네이버 지도, 없으면 OSM fallback을 사용합니다.
- 직원 위치, Tapo 장비, 자동 알림, 운영 통계 API 호출 경로가 연결되어 있습니다.

조건/리스크:

- `/api/staff-locations`, `/api/tapo-*`, `/api/operation-stats`, `/api/forecast-kpi`, `/api/zone-crowd-stats`는 서버 환경 변수 또는 외부 장비 설정이 있어야 실제 데이터가 나옵니다.
- 브라우저 위치 권한을 거부하면 위치 공유/길찾기 기능은 제한됩니다.

### 3. 시설점검

상태: 정상

확인 내용:

- 하위 메뉴: 대시보드, 시설 관리, 체크리스트, 점검 현황, 보완 과제, CCTV, 보고서
- 시설 상세에서 최근 점검/보완과제 확인 가능
- 새 점검 작성, 점검 결과 저장, 승인, 보완과제 자동 생성 흐름이 연결되어 있습니다.
- AI 현장 진단은 사진 업로드 후 보완과제를 생성하는 흐름입니다.
- CCTV 일괄 점검은 스냅샷 서버 또는 API 키/Claude 경로를 사용합니다.

조건/리스크:

- CCTV 스냅샷 서버(`cctv.py` 또는 `http://localhost:5555`)가 없으면 실제 스냅샷 분석은 실패합니다.
- 직접 Claude API 호출 경로는 브라우저 CORS/키 노출 문제가 있을 수 있으므로 서버 프록시 방식이 안전합니다.

### 4. 재고관리

상태: 정상

확인 내용:

- 하위 메뉴: 시설 맵, 제품목록, 필요 재고, 입고, 출고, 조정, 로그, RFID, 분석
- 제품 추가/수정/삭제, 위치별 재고, 활동 로그, 사진, 구역 사진 기능이 연결되어 있습니다.
- 입고/출고/조정 시 `jamsa_inv_prods`, `jamsa_inv_hist`가 갱신됩니다.
- 되돌리기 스냅샷은 최근 50개까지 보관됩니다.
- 제품 상세에서 품의 작성, QR 보기, 라벨 인쇄 진입 가능.

### 5. QR/라벨 인쇄

상태: 정상

확인 내용:

- 단일 QR 모달:
  - `라벨 바로 인쇄`: 50x30mm 라벨 전용 인쇄창
  - `인쇄 (PC/A4)`: 기존 A4 인쇄
  - `라벨프린터(에이블마크)`: PNG 생성 후 공유/다운로드
- 일괄 QR 모달:
  - 검색, 카테고리 필터, 위치 필터, 선택/해제
  - `{n}건 라벨 바로 인쇄`: 50x30mm 라벨을 제품당 1장씩 출력
  - `{n}건 A4 인쇄`: A4 5x5 라벨 시트
  - PNG 공유/다운로드 fallback
- 빌드된 `public/app.bundle.js`에 `.label-page`와 50x30mm 인쇄 CSS가 포함된 것을 확인했습니다.

운영 조건:

- 웹브라우저 보안상 버튼 클릭 없이 무음 직접 출력은 불가합니다.
- 라벨 프린터가 OS/AirPrint/시스템 프린터로 등록되어 있으면 인쇄창에서 바로 선택 가능합니다.
- AbleMark 전용 블루투스 앱만 지원되는 기기는 OS 프린터로 노출되지 않을 수 있어 PNG 공유 방식이 필요합니다.

### 6. 품의/결제/입고 연동

상태: 정상

확인 내용:

- 재고관리 헤더의 `품의/결제`에서 진입합니다.
- 품의 상태 흐름: 작성중 -> 제출 -> 승인 -> 발주 -> 결제완료 -> 입고완료
- 결제 등록 시 연결된 품의가 `paid`로 변경됩니다.
- 입고완료 처리 시 제품 재고가 증가하고 입고 이력이 기록됩니다.
- 결제 내역은 카드/이체 구분, 품의 연결 여부 필터를 제공합니다.

### 7. RFID

상태: 기본 정상

확인 내용:

- 제품별 RFID 태그 할당/해제 흐름이 있습니다.
- 미부착 제품 일괄 태그 할당이 가능합니다.
- 스캔 기록 UI가 존재합니다.

조건/리스크:

- 실제 RFID 리더기와 직접 통신하는 네이티브/Web Serial 연동은 보이지 않습니다. 현재는 앱 내부 태그 관리/스캔 기록 중심 기능으로 판단됩니다.

### 8. 안전관리

상태: 기본 화면 정상, 일부 서버 API 미구현 위험

확인 내용:

- 하위 메뉴: 종합 안전 대시보드, 교육 일지, AI 위험성 평가, 보완조치 관리, 사고/아차사고, 일일 시설점검, 위험지도, 연간 통계
- 교육 일지 작성, 참석자 서명, 사고 기록, 일일 점검, 위험성 평가 등록 흐름이 있습니다.
- AI 위험성 평가 결과를 시설점검 보완과제로 넘기는 흐름이 연결되어 있습니다.

주의 API:

프론트에서 호출하지만 현재 `api` 폴더에 없는 파일:

- `/api/safety-ai-analyze`
- `/api/incident-notify`
- `/api/incident-dispatch`
- `/api/education-tracking`
- `/api/safety-annual-stats`
- `/api/incident-ai-analyze`
- `/api/safety-monthly-report`

이 기능들은 배포 시 404 또는 실패 알림이 날 가능성이 큽니다. 서버 파일을 추가하거나 프론트에서 로컬/시뮬레이션 fallback을 넣어야 합니다.

### 9. 업무일지

상태: 정상

확인 내용:

- 상단 `업무일지` 버튼으로 진입합니다.
- 일간/주간/월간 등 주기별 템플릿을 선택합니다.
- 항목 클릭 시 사진/AI 확인 모달을 통해 완료 처리합니다.
- 서명, 일반 메모, 저장, 과거 기록 조회, 보고서 보기 흐름이 있습니다.
- 저장 데이터는 `jamsa_worklogs`에 보관됩니다.

### 10. 백업/복원/감사로그

상태: 정상

확인 내용:

- `백업`: `jamsa_*` localStorage 데이터를 JSON으로 내보냅니다.
- `복원`: 백업 JSON을 읽어 `jamsa_*` 데이터를 복구합니다.
- `전체 초기화`: 2단계 확인 후 데이터 삭제.
- `활동 기록`: AI 분석, 보완과제 생성, 업무일지 완료 등 주요 활동을 `jamsa_audit_log`에 저장합니다.

주의:

- 초기화는 되돌릴 수 없으므로 운영 전 백업을 먼저 내려받아야 합니다.

## 확인하지 못한 항목

- 인앱 브라우저가 로컬 주소를 `ERR_BLOCKED_BY_CLIENT`로 차단하여 실제 클릭 화면 테스트는 수행하지 못했습니다.
- 실제 라벨 프린터 출력 품질은 프린터/용지/드라이버가 필요합니다.
- Supabase Auth, Vercel 배포 API, Tapo/Roborock/CCTV 실장비 연동은 실제 환경 변수와 장비가 필요합니다.

## 자동 서브에이전트 점검

상태: 정상

확인 내용:

- 상단 공통 메뉴에 `🤖 서브에이전트` 버튼과 추천 조치 배지가 표시됩니다.
- 자동 감시 토글 값이 `jamsa_auto_subagents_enabled`에 저장됩니다.
- 시설 에이전트가 미완료/긴급/기한초과 보완과제를 요약합니다.
- 재고 에이전트가 최소수량 이하 재고와 진행 중 요청서를 요약합니다.
- 안전 에이전트가 최근 사고, 일일 점검, AI 분석 이력을 요약합니다.
- 업무일지 에이전트가 당일 업무일지 작성 여부를 요약합니다.
- 추천 항목의 `이동` 버튼이 시설점검, 재고관리, 안전관리, 통합 업무일지 화면으로 연결됩니다.
- 추천 항목의 `과제 등록` 버튼이 시설 보완과제를 생성하고 활동 기록에 남깁니다.
