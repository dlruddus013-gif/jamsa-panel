# 사용자 매뉴얼

대상 시스템: 한국잠사박물관 통합관리 시스템  
최종 정리: 2026-05-10

## 1. 로그인

1. 프로그램 접속 후 로그인 화면에서 아이디 또는 이메일을 입력합니다.
2. 비밀번호를 입력합니다.
3. `로그인`을 누릅니다.

기본 계정:

| 역할 | 아이디 | 비밀번호 | 권한 |
|---|---|---|---|
| 전체 관리자 | `admin` | `admin1234` | 전체 기능 |
| 관리자 | `mgr` | `mgr1234` | 관리/점검 중심 |
| 점검자 1 | `ins1` | `ins1234` | 점검/업무 처리 |
| 점검자 2 | `ins2` | `ins1234` | 점검/업무 처리 |
| 조회자 | `viewer` | `viewer1234` | 조회 중심 |

## 2. 상단 공통 메뉴

### 홈

- 전체 구역, 보완과제, 재고, CCTV, 직원 위치, 운영 통계를 한 화면에서 봅니다.
- 지도/카드 보기 전환이 가능합니다.
- 네이버 지도 Client ID가 없으면 OSM 지도로 표시됩니다.

### 시설점검

- 시설 목록, 체크리스트, 점검 현황, 보완과제, CCTV, 보고서를 관리합니다.

### 재고관리

- 재고 위치, 제품 목록, QR 라벨, 입출고, 품의/결제, RFID, 필요 재고를 관리합니다.

### 안전관리

- 교육 일지, 위험성 평가, 사고 기록, 일일 점검, 안전 통계를 관리합니다.

### CCTV 관제

- 설정된 외부 CCTV 관제 URL이 있으면 새 창으로 엽니다.
- URL이 없으면 시설점검의 CCTV 화면으로 이동합니다.

### 업무일지

- 일간/주간/월간 업무 점검표를 작성하고 저장합니다.

### 활동 기록

- AI 분석, 보완과제 생성, 업무일지 처리 등 주요 활동 내역을 확인합니다.

### 백업

- 현재 데이터를 JSON 파일로 내보내거나 복원합니다.

## 3. 홈 대시보드 사용법

1. 상단에서 `홈`을 선택합니다.
2. 지도에서 구역 아이콘을 선택하면 구역 상세 정보가 열립니다.
3. 필터를 이용해 전체/긴급/재고/시설 상태를 좁혀 봅니다.
4. 구역 상세에서 관련 보완과제, CCTV, 재고 요약을 확인합니다.
5. `보완과제 등록` 버튼이 보이면 바로 시설점검 과제로 넘길 수 있습니다.

위치 공유:

1. 위치 공유 안내가 나오면 허용합니다.
2. 브라우저 위치 권한을 승인합니다.
3. 직원/방문자 위치가 지도에 표시됩니다.

네이버 지도 설정:

1. 지도 API 설정 버튼을 엽니다.
2. 네이버 클라우드에서 발급받은 Client ID를 입력합니다.
3. 저장 후 새로고침합니다.

## 4. 시설점검 사용법

### 대시보드

1. `시설점검` -> `대시보드`로 이동합니다.
2. 긴급/기한초과 과제, 최근 점검, 빠른 실행 버튼을 확인합니다.
3. `새 점검`, `점검 현황`, `보완 과제`로 바로 이동할 수 있습니다.

### 시설 관리

1. `시설 관리`를 선택합니다.
2. 시설 목록에서 시설명을 클릭합니다.
3. 시설 상세에서 중요도, 점검 주기, 최근 점검, 관련 보완과제를 확인합니다.
4. `점검 시작`을 눌러 해당 시설 점검을 시작합니다.

### 체크리스트

1. `체크리스트`를 선택합니다.
2. 시설 유형별 점검 항목, 기준, 위험도를 확인합니다.
3. 사진 필수 항목은 점검 시 사진을 첨부합니다.

### 새 점검 작성

1. `점검 현황` -> `+ 새 점검`을 선택합니다.
2. 점검할 시설을 선택합니다.
3. 각 항목의 결과를 `정상`, `주의`, `위험`, `N/A` 중 선택합니다.
4. 필요한 측정값과 메모를 입력합니다.
5. 사진이 필요한 항목은 사진을 첨부합니다.
6. 제출하면 승인 대기 상태로 저장됩니다.

### 점검 승인/보완과제 생성

1. `점검 현황`에서 점검 건을 선택합니다.
2. 관리자 권한으로 승인합니다.
3. 위험/주의 항목이 있으면 보완과제를 생성합니다.
4. 생성된 과제는 `보완 과제` 메뉴에서 확인합니다.

### 보완 과제

1. `보완 과제`로 이동합니다.
2. 과제 상태를 `미착수`, `진행중`, `완료`, `재점검필요`로 관리합니다.
3. 담당자, 기한, 조치 메모를 확인합니다.
4. 완료 시 증빙 사진과 AI 확인을 함께 남길 수 있습니다.

### CCTV 점검

1. `CCTV` 메뉴로 이동합니다.
2. 스냅샷 서버 URL 또는 스트림 URL을 설정합니다.
3. 채널을 선택합니다.
4. 일괄 AI 점검을 실행합니다.
5. 이상 항목은 보완과제로 생성합니다.

필요 조건:

- CCTV 스냅샷 서버가 있어야 실제 화면 분석이 가능합니다.
- AI 분석에는 서버 API 또는 Anthropic API 키 설정이 필요합니다.

### 보고서

1. `보고서` 메뉴로 이동합니다.
2. 일간/주간/월간/계절별 보기 중 선택합니다.
3. 기간 내 점검 요약, 보완과제, 결재란을 확인합니다.
4. `인쇄 / PDF`로 출력합니다.

## 5. 재고관리 사용법

### 시설 맵

1. `재고관리` -> `시설 맵`을 선택합니다.
2. 구역을 클릭하면 해당 구역의 재고 목록이 아래에 열립니다.
3. 제품 행을 클릭하면 상세 정보가 펼쳐집니다.
4. 상세에서 위치별 재고, 사용법, 관리법, AI 시세, 활동 로그를 봅니다.

### 제품 추가

1. 상단 `제품 추가`를 누릅니다.
2. 제품명, 카테고리, 위치, 수량, 메모를 입력합니다.
3. 사진을 추가하면 자동 AI 분석이 켜진 상태에서 카테고리/관리법/적정재고가 자동 입력될 수 있습니다.
4. `등록 + QR생성`을 누릅니다.
5. 등록 후 QR 모달이 열립니다.

### 제품 목록

1. `제품목록` 메뉴로 이동합니다.
2. 검색창에 제품명, 코드, 카테고리, 위치를 입력합니다.
3. 카테고리/위치 필터로 좁혀 봅니다.
4. 제품을 선택하면 상세 패널에서 입고/출고/조정/수정/삭제를 실행합니다.

### 입고

1. 제품 상세 또는 `입고` 메뉴로 이동합니다.
2. 제품, 위치, 수량, 메모를 입력합니다.
3. 저장하면 총재고와 위치별 재고가 증가합니다.
4. 활동 로그에 입고 기록이 남습니다.

### 출고

1. 제품 상세 또는 `출고` 메뉴로 이동합니다.
2. 제품, 위치, 수량, 메모를 입력합니다.
3. 저장하면 총재고와 위치별 재고가 감소합니다.
4. 활동 로그에 출고 기록이 남습니다.

### 조정

1. 제품 상세 또는 `조정` 메뉴로 이동합니다.
2. 위치와 조정 후 수량을 입력합니다.
3. 저장하면 해당 위치 수량이 입력값으로 맞춰집니다.
4. 총재고도 함께 재계산됩니다.

### 필요 재고

1. `필요 재고` 메뉴로 이동합니다.
2. 시설 보완과제와 재고를 함께 비교합니다.
3. 부족한 재료를 확인하고 관련 구역/제품으로 이동합니다.

### 로그

1. `로그` 메뉴로 이동합니다.
2. 입고/출고/조정/수정/삭제 내역을 확인합니다.
3. 관리자 권한은 되돌리기 기능으로 이전 스냅샷을 복원할 수 있습니다.

### RFID

1. `RFID` 메뉴로 이동합니다.
2. 제품별 태그를 할당합니다.
3. 미부착 제품은 일괄 할당할 수 있습니다.
4. 태그 스캔 기록을 확인합니다.

### 분석

1. `분석` 메뉴로 이동합니다.
2. 재고 부족, 입출고 추이, 추천 보완과제를 확인합니다.
3. 필요한 경우 시설점검 보완과제로 등록합니다.

## 6. QR/라벨 인쇄 사용법

### 단일 라벨 바로 인쇄

1. 제품의 QR 아이콘 또는 QR 버튼을 누릅니다.
2. QR 모달에서 `라벨 바로 인쇄`를 누릅니다.
3. 새 인쇄창이 열리면 프린터를 라벨 프린터로 선택합니다.
4. 용지 크기를 `50x30mm`, 배율 `100%`, 여백 `없음`, 방향 `가로`로 맞춥니다.
5. 인쇄합니다.

### QR 일괄 라벨 인쇄

1. 재고관리 상단의 `QR 일괄인쇄`를 누릅니다.
2. 검색/필터로 인쇄할 제품을 좁힙니다.
3. 체크박스로 제품을 선택합니다.
4. `{선택수}건 라벨 바로 인쇄`를 누릅니다.
5. 제품마다 50x30mm 라벨 1장씩 생성됩니다.
6. 인쇄창에서 라벨 프린터를 선택해 출력합니다.

### A4 인쇄

1. QR 모달 또는 일괄 모달에서 `A4 인쇄`를 누릅니다.
2. A4 기준 5x5 라벨 시트로 출력합니다.
3. 일반 프린터 또는 PDF 저장에 적합합니다.

### AbleMark 앱으로 보내기

1. `라벨프린터로 보내기`를 누릅니다.
2. 모바일 공유 시트가 열리면 AbleMark 앱을 선택합니다.
3. 공유가 지원되지 않으면 PNG 파일이 다운로드됩니다.
4. AbleMark에서 이미지를 불러와 인쇄합니다.

참고:

- OS에 라벨 프린터가 등록되어 있으면 `라벨 바로 인쇄`가 가장 빠릅니다.
- AbleMark 앱 전용 블루투스 프린터는 브라우저에서 바로 무음 출력할 수 없을 수 있습니다.

## 7. 품의/결제/입고 연동

### 품의 작성

1. 재고관리 상단 `품의/결제`를 누릅니다.
2. `품의` 탭에서 새 품의를 작성합니다.
3. 제품, 수량, 단가, 공급처, 사유를 입력합니다.
4. 저장하면 상태가 `작성중`으로 등록됩니다.

### 상태 진행

1. 품의 행을 클릭합니다.
2. 현재 상태에 맞는 다음 단계 버튼을 누릅니다.
3. 흐름은 `작성중 -> 제출 -> 승인 -> 발주 -> 결제완료 -> 입고완료`입니다.
4. 각 변경은 상태 이력에 남습니다.

### 결제 등록

1. `결제 내역` 탭으로 이동합니다.
2. 결제 방식(카드/이체), 금액, 거래처, 일자를 입력합니다.
3. 진행 중 품의를 연결합니다.
4. 저장하면 연결 품의가 `결제완료` 상태로 변경됩니다.

### 입고 완료

1. 결제 완료된 품의에서 `입고완료`를 누릅니다.
2. 연결 제품 재고가 자동 증가합니다.
3. 활동 로그에 입고 기록이 남습니다.

## 8. 안전관리 사용법

### 종합 안전 대시보드

1. `안전관리` -> `종합 안전 대시보드`를 엽니다.
2. 교육, 위험 요소, 사고, 일일 점검 상태를 확인합니다.
3. 월간 리포트를 생성할 수 있습니다.

### 교육 일지

1. `교육` 메뉴로 이동합니다.
2. `새 교육 일지 작성`을 누릅니다.
3. 교육명, 강사, 참석자를 입력합니다.
4. 참석자 서명을 받습니다.
5. 저장합니다.

### AI 위험성 평가

1. `AI 위험성 평가` 메뉴로 이동합니다.
2. 현장 사진을 업로드합니다.
3. 관련 시설을 선택합니다.
4. AI 분석을 실행합니다.
5. 결과를 보완과제로 등록합니다.

주의:

- 현재 서버에 `/api/safety-ai-analyze` 파일이 없어 배포 환경에서 실패할 수 있습니다.

### 보완조치 관리

1. `보완조치 관리` 메뉴로 이동합니다.
2. 시설점검/AI 평가에서 생성된 과제를 확인합니다.
3. 담당자, 상태, 기한을 관리합니다.

### 사고/아차사고 기록

1. `사고 / 아차사고 기록`으로 이동합니다.
2. 사고 유형, 시설, 설명, 사진을 입력합니다.
3. 저장합니다.

주의:

- 알림 발송/AI 분석 API 일부가 현재 서버에 없을 수 있습니다.

### 일일 시설점검

1. `일일 시설점검`으로 이동합니다.
2. 시설별 점검 상태를 입력합니다.
3. 저장하면 일일 점검 데이터에 반영됩니다.

### 위험지도

1. `위험지도` 메뉴로 이동합니다.
2. 구역별 위험도와 사고/보완 현황을 확인합니다.

### 연간 안전 통계

1. `연간 안전 통계` 메뉴로 이동합니다.
2. 사고, 교육, 점검, 보완 이력을 집계해 봅니다.

## 9. 업무일지 사용법

1. 상단 `업무일지`를 누릅니다.
2. 주기를 선택합니다.
3. 점검 항목을 클릭합니다.
4. 사진을 첨부하고 AI 확인 또는 관리자 직접 완료를 진행합니다.
5. 필요한 메모를 남깁니다.
6. 서명을 입력합니다.
7. `저장`을 누릅니다.
8. 저장된 업무일지는 과거 기록에서 조회하고 보고서로 볼 수 있습니다.

AI 자동작성:

1. 업무일지 화면에서 AI 자동작성 기능을 엽니다.
2. 기준 기간과 참고할 과거 기록/보완과제를 선택합니다.
3. 생성 결과를 확인 후 저장합니다.

## 10. 백업/복원

### 백업

1. 상단 `백업`을 누릅니다.
2. `내보내기`를 선택합니다.
3. `jamsa-backup-YYYY-MM-DD.json` 파일이 다운로드됩니다.

### 복원

1. 상단 `백업`을 누릅니다.
2. 복원할 JSON 파일을 선택합니다.
3. 경고를 확인한 뒤 복원합니다.
4. 페이지를 새로고침합니다.

### 초기화

1. 상단 `백업`을 누릅니다.
2. `전체 초기화`를 선택합니다.
3. 두 번의 확인을 모두 승인하면 데이터가 삭제됩니다.

주의:

- 초기화 전 반드시 백업 파일을 내려받으세요.

## 11. 운영 전 확인 체크리스트

- 라벨 프린터가 OS 프린터 목록에 보이는지 확인
- 50x30mm 라벨 한 장을 테스트 출력해 QR 스캔 확인
- Supabase 환경 변수 설정 확인
- Anthropic API 키 또는 서버 AI 프록시 설정 확인
- CCTV 스냅샷 서버 연결 확인
- Tapo/Roborock 장비 API 환경 변수 확인
- 안전관리 누락 API 구현 여부 확인
- 기본 계정/비밀번호 제거 또는 운영 계정으로 교체

## 12. 자동 서브에이전트

상단 공통 메뉴의 `🤖 서브에이전트` 버튼을 누르면 시설, 재고, 안전, 업무일지 상태를 한 번에 점검하는 관제 패널이 열립니다.

### 자동 감시

1. 패널 우측 상단의 `자동 감시` 체크를 켭니다.
2. 버튼 배지에 현재 추천 조치 수가 표시됩니다.
3. 끄면 배지가 `OFF`로 표시되고, 필요할 때만 수동으로 패널을 열어 확인합니다.

### 시설 에이전트

1. 미완료 보완과제, 긴급도, 기한 초과 여부를 확인합니다.
2. `이동`을 누르면 시설점검 화면으로 이동합니다.
3. 추천 항목에 `과제 등록`이 보이면 눌러 보완과제로 바로 등록합니다.

### 재고 에이전트

1. 최소수량 이하 재고와 진행 중인 요청서를 확인합니다.
2. `이동`을 누르면 재고관리 화면으로 이동합니다.
3. 부족 재고는 입고/구매 요청 처리 후 다시 패널을 열어 상태를 확인합니다.

### 안전 에이전트

1. 최근 사고, 일일 점검 기록, 안전 AI 분석 이력을 확인합니다.
2. `이동`을 누르면 안전관리 화면으로 이동합니다.
3. 사고 또는 점검 누락이 있으면 안전관리에서 상세 기록을 보완합니다.

### 업무일지 에이전트

1. 오늘 업무일지 작성 여부를 확인합니다.
2. `이동`을 누르면 통합 업무일지 화면이 열립니다.
3. 일간 점검표 저장 후 다시 서브에이전트 패널을 열면 상태가 갱신됩니다.
