# 향후 확장 로드맵 — 잠사박물관 BLE 비콘 HR 시스템

> 현재(2026-05-19) 기준 v1.0 완성 상태에서 단계별 확장 계획.
> 각 항목은 **독립적으로 배포 가능**하도록 설계됨.

---

## Phase 2 — 출퇴근 자동화 완성 (1~2개월)

### 2.1 자동 체크아웃
- 비콘이 5분 이상 미감지 → `attendance.checked_out_at` 자동 기록
- Supabase Edge Function 또는 `minew-server` cron 워커가 매분 스캔
- 깜빡임(터널 통과 등) 방지를 위해 **3회 연속 미감지** 후에만 트리거

```sql
-- 추가 컬럼
alter table attendance
  add column if not exists last_seen_at timestamptz,
  add column if not exists auto_closed boolean default false;
```

### 2.2 근무시간 계산 + 야간/주말 가산
- `v_work_hours` 뷰: `checked_out_at - checked_in_at`
- 한국 근로기준법 가산율 자동 적용 (야간 22~06시 = 1.5배, 주휴/공휴일 = 1.5배)
- 4대보험·세금 미리보기 → 급여 계산 모듈로 연결

### 2.3 외출/복귀 기록
- 같은 날 비콘 재감지 시 자동 "외출/복귀" 이벤트 생성
- 점심시간(11:30~13:30) 자동 제외 옵션

### 2.4 지각/조퇴 알림
- 출근 09:00 기준 ±15분 임계값
- 관리부에 카카오톡/SMS 알림 (`/api/notify`)

## Phase 3 — 위치 기반 확장 (2~3개월)

### 3.1 다중 게이트웨이 + 실내 측위
- 게이트웨이 3개 이상에서 같은 비콘 감지 → **삼변측량(trilateration)** 으로 좌표 계산
- 박물관 평면도 위에 직원 점 실시간 표시
- 기존 `panorama-addon.jsx` 의 박물관 지도 좌표계 그대로 사용

### 3.2 구역별 체류 시간
- 전시실/사무실/식당/주차장 폴리곤 정의
- `staff_zone_visits` 테이블에 입실/퇴실 시각 누적
- 일별/주별 히트맵: "관리부 김씨는 전시실 A에 평균 2.3시간 체류"

### 3.3 동선 분석 (관리부 전용)
- 외국인 노동자 동선 → 안전구역 이탈 시 경고
- 시설부 동선 → 점검 누락 구역 자동 검출

### 3.4 SOS / 무신호 경보
- 비콘 신호가 게이트웨이 범위 밖으로 30분 이상 사라지면 SOS
- 안전사고 가능성 → 관리부 즉시 알림
- 외국인 노동자 우선 모니터링 (`dept_code = 3`)

## Phase 4 — 비자/계약 관리 고도화 (3~4개월)

### 4.1 비자 만료 자동 워크플로
- D-90 / D-60 / D-30 / D-7 단계별 알림
- 만료 임박 시 갱신 신청서 자동 생성 (PDF)
- 출입국·외국인청 신청 양식 사전 채움

### 4.2 4대보험 EDI 연동
- 국민연금·건강보험·고용보험·산재보험 가입/상실 신고서 자동 작성
- `attendance` 의 첫 출근일 = 가입일 자동 계산
- 보험료 미리보기 (월 소득 추정 기반)

### 4.3 다국어 안전교육 이수 추적
- E-9 비자 의무 교육 (산업안전 16시간, 한국어 등) 이수증 업로드
- 다국어 UI 토글: 한국어 / 베트남어 / 캄보디아어 / 네팔어 / 태국어
- 미이수자 출근 시 자동 경고

### 4.4 계약 갱신 캘린더
- 정규직/계약직/시급제/외주 4종 자동 분류
- 계약 종료 60일 전 갱신 알림
- 임금 인상률·근로조건 변경 사항 diff 보기

## Phase 5 — 분석·리포팅 (4~5개월)

### 5.1 부서별 KPI 대시보드
- 총 근무시간 / 평균 출근시각 / 결근율 / 야근 빈도
- 부서 비교 차트 (관리부 vs 시설부)
- 월별/분기별 PDF 리포트 자동 생성

### 5.2 인건비 예측
- 과거 6개월 데이터 → 다음 분기 인건비 예측
- 비콘 출근 데이터 기반 정확한 실근무시간 반영
- 박물관 예산 모듈로 결과 송출

### 5.3 이상 패턴 탐지
- 동시 출근(여러 명이 1초 차이로 비콘 감지) → 비콘 공유 의심
- 동일 인물이 두 게이트웨이에서 동시 감지 → 비콘 분실/도용 의심
- 머신러닝(Isolation Forest) 기반 자동 알림

### 5.4 노동부 신고용 출퇴근부 출력
- 법정 양식 (별지 제17호) 자동 작성
- 외국인 노동자별 출근부 분리 출력 (E-9 특별감독 대비)

## Phase 6 — 하드웨어 확장 (5~6개월)

### 6.1 비콘 다양화
- 손목밴드형 (방수, IP67) — 시설부/외국인 노동자
- 카드형 (사원증 일체형) — 관리부
- 자전거/차량용 (긴 안테나) — 출입 차단기 연동

### 6.2 게이트웨이 메시 네트워크
- 박물관 5개동 전체 커버를 위해 게이트웨이 8~12대 배치
- TP-Link Omada Controller 1대로 통합 관리
- 정전 시 자동 페일오버

### 6.3 출입 차단기 연동
- 비콘 감지 + RSSI 임계값 통과 시 자동 개방
- 일반 직원: 정문만 / 관리부: 전관 / 외국인: 작업동만
- 야간/주말 시간외 출입 자동 차단

### 6.4 NFC/QR 백업
- 비콘 배터리 방전 시 NFC 카드 또는 QR 인증으로 대체
- 기존 패널의 QR 인쇄 기능 재사용

---

## Phase 7 — 통합·외부 연동 (6개월 이후)

### 7.1 기존 잠사 패널 통합
- 메인 패널 좌측 메뉴에 "👥 인사관리" 추가
- `/hr` 페이지 → 메인 패널 iframe 또는 직접 통합
- 사고/안전 이벤트 발생 시 → 현장 인원 자동 조회

### 7.2 외부 시스템 연동
- 국세청 홈택스: 원천세 신고 자동화
- 4대보험 EDI: 보험료 신고 자동화
- 카카오워크/슬랙: 알림 채널 연동
- 경찰청 IPS: 외국인 비자 상태 정기 조회 (위탁 API)

### 7.3 모바일 앱 (PWA)
- 직원용: 본인 근무 현황 / 급여 명세서 확인
- 관리자용: 실시간 출근 푸시 알림
- 다국어 (5개국어)
- 오프라인 모드 (IndexedDB 캐싱)

### 7.4 음성 안내 (외국인 대상)
- 비콘 감지 시 본인 언어로 "안녕하세요" 자동 음성 (선택)
- 위험구역 진입 시 본인 언어로 경고

---

## Phase 8 — AI/ML (장기)

### 8.1 출근 패턴 학습
- LSTM 기반 개인 출근 시간 예측
- 평소와 다른 패턴(예: 평소 8:50 → 9:30) → 자동 컨택트

### 8.2 안전사고 예측
- 비콘 동선 + 사고 이력 → 위험구역/시간대 예측
- 점검 일정 자동 우선순위 조정

### 8.3 자동 스케줄링
- 일별 필요 인원 / 비자 만료 / 개인 휴가 신청을 종합해
  주간 근무표 자동 생성 → 관리부 승인만 받음

## 개발 메모

- 모든 신규 기능은 **단일 JSX 파일** 원칙 유지 (museum-hr-page.jsx 또는 분리된 모듈)
- Supabase RLS 정책은 신규 테이블마다 반드시 함께 작성
- 외국인 노동자(`dept_code=3`) 관련 데이터는 항상 **관리부 전용 접근**
- 한국어 UI 우선, 다국어는 i18n 키만 추가 (실제 번역은 Phase 7)
- Windows 11 환경 (관리부 PC 기본) 호환성 유지
